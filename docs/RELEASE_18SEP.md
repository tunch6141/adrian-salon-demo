# Expanded synthetic dataset and connected analyst

This release implements the dataset and working analytical foundation for the 18 September 2026 handoff. It does not claim that every future workflow in the handoff is production-ready.

## Data and reporting clock

- Active dataset: `data/handoff_2026_09_18/raw`, generated by `python scripts/build_handoff_dataset.py`.
- 42 source tables, 2,507 raw booking rows, 2,506 after removing the deliberate duplicate, and transaction/service/availability history from June 2025.
- Fixed reporting clock: 17 September 2026, 18:00 Australia/Melbourne. Future bookings remain future bookings.
- All people, suppliers, invoices, products and commercial events are synthetic. The automotive vehicle row demonstrates the optional extension, not an actual salon vehicle service.
- Original six-CSV demo and original Piece 1 fixture remain unchanged. The version control parent commit is the rollback baseline.
- `test_manifest.json` records scenarios, hashes and stable acceptance outcomes. It is not loaded by the analyst.

## Working changes

- Explicit source paths eliminate duplicate CSV discovery.
- The validation page, Business evidence view and Ask your salon use the same corrected snapshot.
- Confirmed mappings and manual sales are applied once. Data changes invalidate prior analytical chat results.
- Owner context is retrieved by entity and overlapping dates. It never silently changes financial or capacity facts.
- Runtime reporting dates and financial filtering use the business timezone.
- Deterministic views cover financial lines, capacity, completed services, staff productivity, service mix, future workload at equal lead times, retention, staff-associated returns, historical customer value/concentration, inventory, landed costs, analytical cost allocation, quotes/follow-ups, receivables and source action/checkpoint history.
- Dynamic queries remain read-only, one approved view per query, limited in time and result size. Additional investigation rounds and numeric answer binding are retained and tested with simulated model responses.
- No model-authored Python is executed.

## Limits retained explicitly

- Live model wording requires a deployment check with the configured API credentials. Automated interaction tests use simulated model outputs.
- Supabase has not been migrated. Existing analyst context persistence is supported if already configured, but Piece 1 corrections/manual sales still require checkpoint export for durability.
- Operational writes for inventory damage, staff leave, supplier costs and pricing are not automatically performed from chat.
- Source insights/actions/checkpoints can be analysed. Automatic insight ranking, scheduled weekly delivery and a general action-management write workflow are not enabled.
- Supplier allocations are analytical and preserve provenance. They do not replace the accounting system's COGS.
- Gross-profit aggregate queries need complete cost coverage or explicit partial labels. Missing cost is never zero.
- Exact anomaly thresholds, production entitlements/pricing, cash forecasting, operating profit and overhead analysis remain open.
- Existing sale-only ATV is preserved in the validation view. Query evidence exposes transaction type so other denominators must be explicitly labelled.
- Posting-period productivity is unavailable when the service sale and completed-service period cannot be reconciled.

## Development checks

Install the repository requirements plus pytest. Run `python -m pytest tests -q`.
Tests cover old behaviour, deterministic regeneration, source relations, current corrected snapshots, costing provenance, capacity, optional data, context scope, timezone boundaries, SQL restrictions and Streamlit interactions.

Verified on 19 September 2026 with Python 3.12: **73 tests and 9 validation subtests passed**. Streamlit interaction tests use simulated model responses and no live API credentials. The run reported 365 NumPy/pandas deprecation warnings in the archived demo paths; no test failed. Original dummy CSVs and the original Piece 1 raw fixture are unchanged.
